## ❓/ 개요
이중진자는 카오스 이론을 말할 때 한 번씩 언급되곤 하는 주제입니다.
실제로 이중진자의 궤적은 예측하기가 매우 힘들며, 
수학적으로 일반해를 구해내는 것 또한 불가능합니다.
그러나 오일러-라그랑주 방정식이나 뉴턴역학을 기반으로 하여 각가속도의 관계식등을
알 수 있으며, 이를 바탕으로 수치해석을 적용하여 이중진자의 궤적을 시뮬레이션 할 수 있습니다.

##### 본 프로젝트는 이를 바탕으로 하여 파이썬을 통해 이중진자 궤적을 시뮬레이션 할 수 있게 만들었습니다.
